# 更新日志

本文件记录课程复习 Agent 的主要功能、修复、文档和验证变化。内容以 Git 提交为依据；尚未实现的规划会明确标记为待办，不计入已交付功能。

## 2026-08-05：PetPresence 小比熊虚拟形象

- 从团队自有的 MIT 开源项目 `xytsakura/PetPresence-public` 引入经过公开资源审计的小比熊 Demo：六个透明 WebM 动作和一张播放失败海报均保留来源提交与许可证。
- 虚拟形象设置新增“小比熊”，同时保留原有男生、女生形象；新用户默认使用小比熊，既有用户保存的选择继续生效。
- 小比熊的待机、警觉、玩耍和进食动作分别接入 Agent 的待机、模型思考、点击互动和陪伴学习状态；非循环动作结束后恢复待机。
- 支持把鼠标悬停在角色上直接滚轮缩放，沿用现有用户级缩放持久化、滑杆、按钮、拖动和输入区边界保护。
- 在减少动态效果模式下不自动播放视频，只显示首帧/海报；透明 WebM 无法播放时保留小比熊海报回退。
- 自动化验证为 Python `78` 项、JavaScript `8` 项全部通过，并单独执行前端语法检查和 WebM 静态资源校验。

## 2026-08-04：免费订阅知识库广场

- 新增“知识广场”一级视图，支持浏览公开课程知识库、查看资料策略、订阅、取消订阅和进入独立只读知识空间。
- 个人空间可明确选择资料投稿；服务端复制为不可变快照，个人原文后续修改或删除不会改变已提交版本，未勾选资料不会进入快照。
- 管理员可以逐份调整 `use_in_rag`、`can_preview`、`can_download`，并批准、要求修改或拒绝；作者不能审批自己的投稿。

- 订阅关系与邀请制 `memberships` 分离；FTS 检索先获得当前用户的授权文档 ID，再只在授权集合内搜索。
- 未订阅登录用户只能预览明确允许预览的当前公开资料；下载与 RAG 必须同时满足有效订阅和逐份策略。作者与管理员拥有独立审阅权限，不伪装成订阅者。
- 新增普通访客 `demo-c`，与管理员 `demo-a`、投稿作者 `demo-b` 共同覆盖三种角色。
- 自动化测试覆盖投稿、审核、订阅权限、策略矩阵、取消订阅、暂停恢复、换版、回滚、基础版本冲突、旧 ID 失效，以及多文档投稿失败后的数据库、FTS 和文件清理。

## 2026-08-04：多段引用与 GPT-5.6 独立解释分支

- 助手回答支持文本选择工具条：可把最多 8 段、合计不超过 4000 字的片段加入下一轮主对话引用篮，也可以直接在源回答下方打开独立解释分支。
- 主对话引用以可删除、可上下调整顺序的结构化条目展示，不修改用户输入正文；提交时通过 `context_references` 传给服务端，并在模型提示中与用户指令隔离。
- 每条助手消息使用稳定消息 ID；独立分支包含源回答、所选片段、多轮问题与回答，支持折叠、重新打开和把分支回答手动回引主对话。
- 分支随原会话保存在浏览器 `localStorage`，恢复历史会话后继续可用；尚不提供跨设备同步。
- 新增 `/api/branch-query`：固定使用服务端 `COURSE_AGENT_BRANCH_LLM_MODEL`（默认 `gpt-5.6-sol`）和 direct 模式，不接受资料范围或浏览器自选模型，始终返回空引用列表。
- 对引用片段、完整源回答、问题和分支历史增加结构与长度校验；提示词明确把引用视为不可信数据，防止其中的指令覆盖系统边界。

- **王梦莲前端**：瀚海行品牌与 Logo、深浅主题、日程表、个人信息与头像裁剪、男女虚拟形象及动作、虚拟形象快捷功能、天气接口、功能开关、响应式布局和相关专项测试。

### 模型调用恢复与兼容

- **恢复 Responses API 调用链路**（`ba67589`）：重新按 Responses-compatible 协议发送模型请求，兼容 `output_text` 和结构化 `output` 文本提取，保留多轮上下文与知识库引用。
- **错误降级与密钥脱敏**：模型网络错误、HTTP 错误、空响应和缺失引用会返回可解释的降级结果；错误信息不会暴露 API Key 或 Bearer 凭据。
- **回归测试补强**：增加 Responses 请求体、多轮历史、引用、异常响应、凭据脱敏和降级行为测试。

### 个性化 Agent 回答

- **瀚海行 Agent 身份提示词**（`de0df47`）：直接问答和知识库问答都使用统一产品身份，不再把助手只描述为底层通用模型。
- **语气设置**：支持“亲和”和“务实”。
- **回答详略**：支持“简洁”“均衡”“详细”，只控制最终答案篇幅，不控制模型思考强度。
- **个人补充要求**：用户可填写自定义偏好；该内容作为独立用户上下文传给模型，不拼入 system prompt，不能覆盖真实性、权限或引用规则。
- **按用户保存**：个人回答偏好保存在当前用户的浏览器空间中，切换身份时同步切换。

### 多模型、思考强度与上下文用量

- **模型自动发现**（`16fad69`）：管理员可基于已保存的 Base URL 和 API Key 查询服务暴露的模型，并区分可用文本模型与不可用模型。
- **会话级模型选择**：每个会话可选择不同模型；恢复历史会话时同时恢复该会话的模型设置。
- **会话级思考强度**：支持“快速、均衡、深度、极深、最高（高级）”，并按模型能力决定是否显示与传递该参数。
- **上下文用量圆环**：解析 Responses API 的输入、输出、推理、缓存和总 token；结合模型上下文窗口显示本轮使用比例。
- **安全边界**：API Key 只保存在服务端，不返回浏览器；只有管理员身份能保存模型服务配置和执行模型发现；外部 Base URL 默认要求 HTTPS，本机地址需显式开启。
- **回退与缓存**：模型目录不可用时可回退到已保存模型或缓存结果，避免设置页完全失效。

### 引用原文与资料阅读器

- **引用可点击**（`3c8c159`）：回答中的 `[S1]` 等标记和引用卡片可以直接打开对应资料与页码。
- **原始页面/提取文本双视图**：阅读器支持查看后端渲染的 PDF 原页，也可切换到该页的提取文本。
- **翻页与外部打开**：可在阅读器内前后翻页，也可在新标签页打开原始 PDF。
- **权限与缓存控制**：文件、页文本和页图片接口都会重新校验当前用户权限；私有内容使用 `private, no-store`，页面渲染带并发限制和有界缓存。
- **桌面与移动端**：桌面端为可调整宽度的右侧阅读器；移动端切换为全屏对话框，并处理焦点恢复和背景不可交互状态。

## 2026-07-26

### 新增
- **多轮对话（同一窗口连续追问）**：首页问答改为「可滚动会话区 + 固定底部输入框」的聊天式布局，新的回答累加在输入框上方。
- **开启新对话**：仅当用户点击「开启新对话」时才清空窗口并开始一个新会话；在此之前连续追问会保留完整上下文。
- **会话历史操作菜单**：左侧每条历史记录新增三点操作菜单，支持：
  - 置顶 / 取消置顶（置顶项自动排到顶部并显示绿色标记）；
  - 重命名（弹窗输入新名称，长度上限 2000 字）；
  - 删除（二次确认后移除）。
- **点击历史恢复完整会话**：点击某条历史记录可回到当时的对话，完整还原用户问题与助手回答（含 Markdown 与公式渲染），并恢复对应的问答模式。
- **会话持久化**：历史记录（标题、预览、置顶状态、模式、完整消息流）保存到浏览器 `localStorage`，刷新后保留；当前正在查看的会话会高亮。

### 后端
- `QueryRequest` 新增 `messages` 字段（`list[ChatMessage]`），用于接收前端拼接的多轮上下文。
- LLM 适配器 `generate_direct` / `generate` 支持 `history` 参数，按 `system + 历史 + 当前问题` 构造请求。
- 新增 `_sanitize_history()`：过滤非法角色、空内容，并对超长历史做截断。

### 修复
- 修复点击会话历史恢复时因「遍历数组的同时向同一数组追加元素」导致的**死循环卡死**；改为基于快照遍历、并新增只渲染气泡不修改状态的 `appendHomeMessageBubble()`。
- 修复恢复会话时只渲染用户问题、丢失助手回答的问题，现在同时还原助手回答内容。

### 测试
- 新增 pytest 回归用例：验证多轮对话历史按序拼接、非法历史条目被正确过滤；全部用例通过。

### 新增（首页问答模式切换）
- **直接问答 / 知识检索 模式切换**：首页底部输入框左下角新增两个模式按钮。
  - 直接问答：使用默认通用大模型，不调用知识库检索。
  - 知识检索：基于当前知识库资料进行回答。
- **知识检索资料选择面板**：切换到知识检索后，输入框内展开资料选择面板，支持按资料类别选择、选择全部资料、清空、以及单独勾选具体资料；主页与知识库页面的选择状态实时同步。
- **当前模型显示**：对话框右侧展示当前使用的模型名称（如 `gpt-5.6-sol`），登录或保存模型设置后自动刷新；请求返回后也会以后端实际模型名更新。
- **历史会话保留模式**：恢复历史会话时回到该会话最后使用的问答模式。

### 修复
- 修复 pytest 在 Python 3.9 环境下收集阶段失败的问题：`QueryRequest` 的 `scope` 与 `space_id` 字段由 PEP 604 联合注解（`Literal[...] | None`、`str | None`）改为 `typing.Optional[...]`，使 Pydantic 在 Python 3.9 可正常求值；其余 `@dataclass` 字段与函数签名因已使用 `from __future__ import annotations` 不受影响。

### 新增（四面板边界可拉伸）
- **侧边栏 / 知识库空间列表 / 文档列表 / 问答栏** 之间的边界均可拖拽调整宽度，带最大最小限制：
  - 侧边栏：200–400px（默认 260px）
  - 知识库空间列表：200–380px（默认 260px）
  - 问答栏：320–720px（默认 420px）
- **持久化**：拖拽后的宽度会保存到 `localStorage`，刷新或重新登录后保留。
- **键盘可访问**：聚焦分隔条后可用 `← / →` 微调（`Shift` 加大步长）。
- **触屏支持**：兼容移动设备触屏拖拽。
- **拖拽过程**：拖动时全局锁定文本选择与光标为 `col-resize`，避免误选文字。
