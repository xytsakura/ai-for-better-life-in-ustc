# 自托管字体来源

本目录字体用于 Campus Agent Hub 的本地 Web 字体系统，运行时不依赖 Google Fonts 等远程字体服务。

- `inter-latin-wght-normal.woff2`：来自 `@fontsource-variable/inter@5.3.0`，字体项目为 Inter，许可证为 SIL Open Font License 1.1。
- `noto-sans-sc-*-wght-normal.woff2`：来自 `@fontsource-variable/noto-sans-sc@5.3.0`，字体项目为 Noto Sans Simplified Chinese，许可证为 SIL Open Font License 1.1。
- `noto-serif-sc-*-700-normal.woff2`：来自 `@fontsource/noto-serif-sc@5.3.0`，字体项目为 Noto Serif Simplified Chinese，许可证为 SIL Open Font License 1.1。

对应许可证文本保存在本目录的 `LICENSE-*.txt` 文件中。
