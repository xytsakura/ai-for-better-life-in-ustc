# AI for better life In ustc

本仓库是队伍 **AI for better life In ustc** 参加中国科学技术大学“一〇七”杯算力与智能体开发大赛的团队协作仓库。

## 参赛信息

- 参赛组别：本科生组
- 参赛赛道：智能体赛道
- 团队规模：3 名本科生
- 报名状态：已完成报名
- 当前阶段：选题与方案讨论

## 项目背景

比赛鼓励参赛队伍围绕智慧科大校园场景，在教学赋能、科研支持、校园生活和服务管理等方向开展智能体设计与开发。

我们的队伍希望从真实的校园需求出发，探索人工智能和智能体技术如何改善学习、科研与校园生活体验。在选题和开发过程中，我们会同时关注作品的创新性、实用性、技术难度和完成度，逐步形成一个能够实际演示、清晰说明并具有进一步发展空间的参赛作品。

目前具体方案仍在讨论中。本仓库将用于共同保存比赛资料、方案记录、设计文档和后续项目代码，让团队成员能够同步进展并查看每次修改的内容。

## 协作方式

团队采用轻量协作方式：重要方向先在群内讨论，形成的结论和项目文件再提交到本仓库。每次提交应使用简短、清楚的说明，方便其他成员了解本次更新内容。

开始修改前先获取最新内容：

```bash
git pull
```

完成修改后提交并推送：

```bash
git add .
git commit -m "说明本次修改内容"
git push
```

发生冲突时，应先检查并合并双方修改，不要直接覆盖其他成员的工作。
