# Hub 与瀚海行默认深色主题设计

## 背景

Hub 与瀚海行的正式视觉均围绕深色界面完成，浅色主题目前仅作为用户可选的兼容能力。因此，任何没有有效主题偏好的新会话都应首先展示深色界面，避免未完成设计的浅色界面成为产品第一印象。

## 行为约定

- Hub 与瀚海行首次访问时默认使用深色主题。
- 浏览器中不存在主题记录，或记录值非法、损坏时，统一回退到深色。
- 用户主动选择浅色后继续保存并恢复浅色，不在后续访问时强制覆盖。
- Hub 用户主动选择“跟随系统”后继续保存该选择；只有无有效偏好时才使用深色。
- 页面在加载样式前确定初始主题，避免先闪现浅色再切换到深色。
- “默认主题”的改变不删除浅色样式，也不重做现有视觉系统。

## 实现范围

- 为 Hub 提供可独立测试的主题归一化函数，仅接受 `dark`、`light`、`system`，其余输入统一返回 `dark`。
- Hub 在 CSS 加载前运行最小启动脚本，读取并归一化已保存主题；主应用、按钮文案和星空效果只能读取归一化后的主题值。
- 保持瀚海行加载前主题脚本与应用初始化使用相同的默认规则。
- 为两个前端补充可执行行为测试，覆盖无记录、有效记录和非法记录；Hub 额外覆盖 `system` 以及主模块尚未执行时的首屏主题。
- 将本地演示浏览器切换为深色，供当前 Demo 验收。

## 验收标准

1. 清除主题偏好后访问 Hub 和瀚海行，两者均直接呈现深色。
2. 主动切换浅色并刷新后，仍保持浅色。
3. 写入非法主题值后刷新，两者均回退深色。
4. Hub 主动选择“跟随系统”后刷新，仍保持该选择。
5. Hub 主应用脚本延迟执行时，CSS 首次计算仍使用已保存且合法的主题；非法值不得使星空进入“跟随系统”分支。
6. 现有主题切换、星空效果和瀚海行设置页功能不回归。
