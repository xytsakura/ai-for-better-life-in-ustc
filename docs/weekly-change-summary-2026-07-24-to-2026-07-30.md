### 7.2 与 Agent 的交互

- Agent 开始生成回复时切换为思考姿态，结束或失败后恢复待机。
- 第一次点击人物时，人物挥手并显示“你好呀，用户名”。
- 5 秒内再次点击时，人物切换为看书姿态并显示学习名言。
- 学习语录已扩充为 8 条，按顺序循环：
  1. 《论语》：学而不思则罔，思而不学则殆。
  2. 《论语》：温故而知新，可以为师矣。
  3. 《论语》：知之者不如好之者，好之者不如乐之者。
  4. 《荀子·劝学》：不积跬步，无以至千里；不积小流，无以成江海。
  5. 韩愈《进学解》：业精于勤，荒于嬉；行成于思，毁于随。
  6. 陆游《冬夜读书示子聿》：纸上得来终觉浅，绝知此事要躬行。
  7. 《礼记·中庸》：博学之，审问之，慎思之，明辨之，笃行之。
  8. 朱熹《观书有感》：问渠那得清如许？为有源头活水来。
- 拖动结束后会抑制紧随其后的点击，避免误触发挥手动作。

### 7.3 拖动、键盘和响应式能力

- 支持鼠标和触屏拖动，可从右侧移动到首页左侧。
- 拖动边界同时考虑人物、四个快捷按钮和缩放控件，并保留 8px 视口边距。
- 支持方向键移动、`Shift + 方向键`快速移动、`Home` 复位。
- 窗口大小或响应式断点变化时，会重新约束人物位置。
- 支持 `prefers-reduced-motion`，减少动画偏好下不会强制播放复杂动作。
- 桌面端个人设置仍保持左侧纵向分类、右侧内容的布局；仅在 900px 以下转为顶部横向滚动页签。

## 9. 天气后端

### 9.1 已完成

- 新增需登录访问的 `GET /api/weather/today`。
- 后端固定访问 `https://api.open-meteo.com/v1/forecast`。
- 固定中国科学技术大学坐标 `31.8206, 117.2272` 和时区 `Asia/Shanghai`。
- 只查询当天数据。
- 返回内容包括：
  - 中文天气描述；
  - 当前、体感、最高、最低温度；
  - 湿度；
  - 最大降水概率；
  - 风速和风向；
  - 日出、日落；
  - 中文摘要。
- 覆盖常用 WMO 天气码的中文说明。

### 9.2 安全与失败处理

- 不接受前端提供 URL、经纬度或时区。
- 调用者即使附带恶意 `url`、`latitude`、`longitude` 参数，后端也会忽略。
- 禁止跟随重定向。
- 连接超时为 3 秒，读取超时为 8 秒。
- 未登录访问返回 401。
- 上游错误、超时或响应格式错误统一返回可重试的 `502 weather_upstream_unavailable`。

### 9.3 实测与限制

- 本机真实联网请求已经成功返回 2026-07-30 合肥天气。
- 自动化测试使用 `httpx.MockTransport`，不依赖外部网络，也不会产生费用。
- 当前地点固定，不支持用户定位或其他城市。
- 当前没有天气缓存、服务端限流、熔断、空气质量、预警或未来天气。
- 测试尚未单独覆盖“HTTP 200 但 JSON 字段畸形”的分支，尽管实现会将其转为 502。

## 11. 用户隔离、异步状态与可访问性

### 11.1 用户隔离

- 个人资料使用 `course-agent:profile-v1:<user-id>`。
- 日程使用 `course-agent:schedule-v1:<user-id>`。
- 功能偏好使用 `course-agent:features-v1:<user-id>`。
- 历史会话继续按用户隔离。

### 11.2 异步状态修复

- 登录切换会递增认证代次和查询请求 ID。
- 旧用户发起的 Agent 或天气响应不会回写到新用户界面。
- Agent 查询期间禁用模式切换、知识源选择、历史切换、空间切换和其他冲突操作。
- 天气请求取消或失败后会正确恢复人物待机状态。
- 退出登录会先清理服务端会话，再重置前端认证和查询状态。
- 切换身份前会清空旧空间、文档、设置和模型显示，避免短暂泄露上一身份状态。

### 11.3 可访问性与输入方式

- 裁剪、计划、教务导入和登录弹窗均纳入焦点陷阱和 `Escape` 关闭逻辑。
- 虚拟形象支持键盘移动和 `Home` 复位。
- 缩放使用原生范围输入并提供无障碍名称和状态播报。
